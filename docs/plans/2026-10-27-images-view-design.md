# 本地图片云盘

使用 Vue、Vue Router、Pinia、Vite、Ant Design Vue 和 Express。以命令执行目录为根目录，构建并 npm link 后可从任意目录运行 images-view。

## 功能

- 中文网盘界面、懒加载目录树、面包屑、列表和缩略图、排序、递归搜索和全部图片。
- 文件夹创建和重命名，图片批量上传、预览、下载，批量移动和删除。
- 删除移入根目录 .images-view-trash，支持恢复及确认后永久删除。
- 缩略图缓存到系统临时目录，不修改原件；无数据库，刷新即重新读取文件系统。
- CLI 默认仅监听本机，自动打开浏览器，默认端口占用自动顺延。

## 边界

不跟随符号链接或 junction，禁止越过根目录。上传验证实际图片内容，不覆盖同名文件。变更接口验证来源及会话令牌。批量操作逐项返回结果，提示部分失败。

## 验证

临时目录集成测试覆盖中文、多层目录、上传、冲突、移动、回收站及路径边界；构建、打包和 npm link 验证；浏览器核心操作和响应式布局验证。
